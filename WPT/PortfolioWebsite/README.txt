POONAM SONAWANE - PERSONAL PORTFOLIO

Files:
- index.html: Home page
- projects.html: Projects page
- contact.html: Contact form page
- style.css: Shared CSS stylesheet
- images/: logo and placeholder profile illustration
- js/: intentionally empty as required by the assignment

HOW TO OPEN:
1. Extract the ZIP file.
2. Open the Poonam_Portfolio folder.
3. Double-click index.html to open it in a browser.
4. Use the navigation links to visit Projects and Contact.

BEFORE SUBMISSION:
- Replace images/profile-placeholder.svg with your real profile photo (keep a supported image file in images/ and update the src path in index.html).
- Replace the GitHub and LinkedIn home URLs with your actual profile URLs.
- Check your education wording and add or correct details as needed.
- The contact form action uses example.com as a dummy URL, as the assignment requests. It does not actually send messages.
- The subscribe form is a front-end demo and does not store email addresses.
- Projects are honestly labelled as practice work or learning work; update them as you complete real projects.
- Test every page, link, image, and stylesheet in a browser.

This assignment uses only HTML and CSS; no JavaScript has been added.
